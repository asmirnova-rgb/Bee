# Research: Настройки — персонализация, память, приватность

**Продукт:** Perplexity-like AI-поиск | **Фича:** Настройки (персонализация, память, приватность, профиль)
**Волна:** 4 | **Версия:** 1.0 | **Дата:** апрель 2026

***

## Связь с предыдущими фичами

Настройки — это скрытая системообразующая фича. Память напрямую влияет на качество инпута (research-input): чем больше система знает о пользователе, тем точнее саджесты и интерпретация запроса. Персонализация меняет главный экран (research-main-screen): empty state и онбординг адаптируются под профиль. Тарифные настройки связаны с paywall-поведением (research-pricing). Приватность и incognito — часть доверия, которое начинается ещё в неавторизованной зоне (research-unauth-zone). Хранение артефактов и история чатов (research-chat-history, research-artifact-create) — управляются тоже из настроек.

***

## 1. Что входит в «Настройки» для такого продукта

Настройки для AI-поиска — не просто форма с полями. Это управление тем, насколько продукт «знает» пользователя и насколько пользователь доверяет продукту. Четыре смысловых блока:

| Блок | Что входит |
|---|---|
| **Профиль** | Имя, аватар, язык интерфейса, часовой пояс |
| **Персонализация** | Инструкции для AI, предпочтения ответов, тон, уровень детализации |
| **Память** | Что помнит AI, просмотр/удаление воспоминаний, incognito-режим |
| **Приватность и данные** | История чатов, обучение на данных, экспорт, удаление аккаунта |

## 2. Боли и потребности

### Jobs to be done

Пользователь нанимает настройки чтобы: (а) объяснить AI «кто я и как отвечать мне», (б) контролировать что AI помнит и что нет, (в) исправить нежелательное поведение.

**Ключевые боли:**

- **AI не помнит контекст между сессиями** — пользователь каждый раз объясняет кто он и что ему нужно. Это чувствуется как «разговор с новым человеком каждый раз».
- **Не понимаю что AI запомнил** — если система собирает данные молча, пользователь либо не знает об этом (тревожно), либо не может это использовать (бесполезно).
- **Нет «режима без памяти»** — в рабочих или чувствительных запросах пользователь хочет быть уверен что это не сохранится.
- **Инструкции игнорируются** — известная проблема Perplexity Spaces: custom instructions перестают работать через несколько сообщений в длинном диалоге. Пользователь настроил поведение AI — но оно не выполняется.
- **Нельзя объяснить AI «я профессионал в теме X»** — ответы слишком базовые, нет способа задать уровень аудитории глобально.

## 3. Конкуренты — как решили

### Perplexity: Memory (март 2026)

**Что есть:** Memory — отдельная фича. При использовании продукта система автоматически сохраняет предпочтения. Воспоминания видны в Settings → Memory. Можно управлять: редактировать, удалять конкретные записи, отключить целиком. Reference Search Library — отдельная опция: система может учитывать предыдущие чаты как контекст.

**Ограничение:** Нет incognito-режима в основном интерфейсе (только Spaces имеют изоляцию). Custom instructions в Spaces деградируют в длинных диалогах.

### ChatGPT: двухуровневая память (2025–2026)

**Что есть:** Explicit Saved Memories (пользователь явно одобряет) + Implicit Memories (AI сам замечает паттерны). Управление через Settings → Personalization → Memory. Temporary Chat — режим без памяти для любого диалога. Кастомные инструкции (1500 символов), управление уровнем детализации.

**Ограничение:** Сложно понять разницу между explicit и implicit memory — пользователи путаются.

### Разрыв который никто не закрыл

Ни у кого нет понятного UI для «объясни AI кто ты» без текстового поля с инструкциями. Пользователь вынужден писать промпт вместо того чтобы заполнить структурированный профиль: профессия, уровень экспертизы, предпочтительный тон ответов, язык.

## 4. Критерии хорошего решения

### Измеримые
- % пользователей заполнивших хотя бы один профильный параметр > 30%
- % пользователей включивших память > 50%
- Количество удалений воспоминаний как % от созданных < 20% (сигнал что система сохраняет релевантное)
- Custom instructions соблюдаются на протяжении всего диалога

### Субъективные
- «Продукт меня понимает» — ощущение персонализации без ощущения слежки
- Управление памятью понятно без инструкции
- Incognito-режим ощущается как «защищённо», а не «скрываю что-то плохое»

## 5. Рекомендации

### R1 — Структурированный профиль вместо текстового поля

**Сделать так:** Вместо (или в дополнение к) текстовому полю «кастомные инструкции» — структурированная анкета:
- Профессия / сфера деятельности (свободный ввод или выбор из категорий)
- Уровень экспертизы в темах (новичок → эксперт; по категориям)
- Предпочтительный формат ответов (коротко / подробно / с примерами / только факты)
- Язык ответов (русский / английский / как в вопросе)

*Почему:* Структурированный ввод точнее и быстрее. Параметры не деградируют в длинных диалогах в отличие от текстовых инструкций.

### R2 — Память: явная + управляемая

**Сделать так:** Раздел «Моя память» в настройках. Память создаётся двумя путями: (а) AI сохраняет автоматически после явных упоминаний («я работаю дизайнером», «мне нравится краткий формат»), (б) пользователь добавляет вручную. Каждое воспоминание — карточка: текст + откуда взялось + дата. Удалить → одним кликом. Toggle: включить/выключить всё.

*Почему:* Perplexity Memory — правильная механика, но непрозрачная. ChatGPT — прозрачная, но сложная. Нужна золотая середина: видно всё, управляется легко.

### R3 — Incognito-режим как первоклассный паттерн

**Сделать так:** В поле ввода или в хедере — иконка «Без памяти» (не прячем в настройках). Активация: один клик. Визуальный индикатор что режим включён. Запрос не сохраняется в истории, не создаёт воспоминаний. По умолчанию — следующий запрос снова с памятью (не залипает).

*Почему:* Рабочие, личные, чувствительные запросы. Пользователь должен управлять этим без захода в настройки.

### R4 — Настройки уведомлений в онбординге, не в дебрях настроек

**Сделать так:** В онбординге — один экран «Как тебя уведомлять?» с двумя опциями: «Сразу о важном» / «Только по делу». Не грузить тонкими настройками пока пользователь сам не захочет.

### R5 — Экспорт и удаление данных — заметно, не спрятано

**Сделать так:** В настройках Privacy раздел «Мои данные»: Экспортировать всё (.zip), Удалить историю чатов, Удалить память, Удалить аккаунт. Каждый пункт — с объяснением что именно удаляется. Подтверждение перед удалением.

*Почему:* 152-ФЗ требует. Плюс это сигнал доверия — если пользователь видит что данные можно удалить, он охотнее их оставляет.
