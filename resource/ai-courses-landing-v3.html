Что важно знать

Claude Code доминирует
9 из 13 курсов — про Claude Code. GitHub Copilot представлен двумя курсами от Microsoft. Cursor, Codex, Gemini — ноль структурированных курсов.
PM-курс задал формат
Интерактивные slash-команды как уроки, ролевой контекст, прогрессия модулей. Уже реплицирован для маркетологов. Формат воспроизводим для других ролей.
Дефицит для нетехнических ролей
Дизайнеры, проджект-менеджеры, аналитики, HR — без покрытия. Нетехнические роли обслуживаются только 3 ресурсами из 13.
Проджект-менеджеры — ноль
Ни одного курса для проджект-менеджеров ни по одному инструменту. Полностью пустая ячейка в матрице покрытия.
Корпоративное обучение — пусто
Только 1 repo (kousen) в формате instructor-led training. B2B/корпоративный образовательный сегмент не освоен.
11 курсов без лицензии
54% найденных курсов не имеют OSS-лицензии. Это коррелирует с монетизацией: платные курсы с бесплатным GitHub-preview.
