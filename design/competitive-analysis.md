# Конкурентный анализ: AI-поиск на российском рынке
> Черновик для подготовки к кик-оффу. Данные на март 2026.
> Версия: 0.1 | Статус: личный черновик

## Быстрое сравнение

| | Perplexity | Яндекс Нейро | Алиса AI | GigaChat |
|---|---|---|---|---|
| **Тип** | Standalone AI-поиск | Встроен в Яндекс Поиск | Standalone + встроен | Standalone чат |
| **Фокус** | Информационный поиск с источниками | Поиск + экосистема Яндекса | Универсальный ассистент | Универсальный ассистент |
| **Навигация** | Минимальная, диалог в центре | Вкладка в поиске + отдельный режим | Поле ввода + история + агенты | Сайдбар + история + проекты |
| **Источники** | Всегда, hover-сниппеты | Всегда, со ссылками | Есть, со структурой | Появились в 2.0 (2025) |
| **Мобайл** | Приложение iOS/Android | Через Яндекс Браузер | Отдельное приложение — топ-1 App Store | Приложение есть |
| **Голос** | Нет | Есть (через Алису) | Да, основная фича | Есть |
| **Доступ в РФ** | Без VPN | Без VPN | Без VPN | Без VPN |
| **Регистрация** | Опционально | Яндекс ID | Яндекс ID | Sber ID |
| **Бесплатно** | Базовый план | Да | Да (с июля 2025) | Да |

## Детальный разбор

### Perplexity
**Сильные стороны:**
- Лучший UX среди всех: минималистичный, быстрый, понятный
- Hover на источнике — сниппет без перехода
- Follow-up вопросы автоматически предлагаются
- Pro Search показывает план выполнения шаг за шагом
- Discover-раздел для вовлечения без запроса

**Слабые стороны для российского рынка:**
- Интерфейс на английском по умолчанию — барьер для части аудитории
- Русскоязычные источники есть, но ранжируются хуже чем у Яндекса
- Локальный контекст слабее: организации, цены, региональные события — Яндекс знает лучше
- Не интегрирован в привычные российские сервисы

**Навигация:** главная → поле ввода → ответ → follow-up. Всё.

---

### Яндекс Нейро / Алиса AI в Поиске
**Сильные стороны:**
- Огромная аудитория: 51 млн пользователей в ноябре 2025
- Локальные источники — рунет, актуальные данные
- Интегрирован в привычный Яндекс Поиск — нулевой порог входа
- Понимает локальный контекст (организации, карты, цены)
- Честно предупреждает об ошибках: «ответ может содержать неточности»
- История запросов, возможность продолжить с места остановки

**Слабые стороны:**
- Встроен в поиск — не самостоятельный продукт, теряется в интерфейсе
- UX перегружен функциями экосистемы Яндекса
- Переключение между классическим поиском и AI-режимом неочевидно
- Качество ответов на сложные запросы хуже Perplexity

**Навигация:** кнопка «Алиса AI» под поисковой строкой → режим диалога → история в боковой панели

---

### Алиса AI (отдельное приложение)
**Сильные стороны:**
- Топ-1 App Store после запуска в октябре 2025 — массовое принятие
- Структурированные ответы с картинками, видео, карточками организаций
- Голосовой ввод как основная фича
- «Моя память» — запоминает планы пользователя
- ИИ-агенты: заказ такси, поиск товаров, исследования
- Умная камера (распознавание предметов, перевод надписей)
- Работает без VPN

**Слабые стороны:**
- Перегружен функциями — сложно понять главное
- Позиционирование размыто: и поиск, и ассистент, и агент
- Привязан к Яндекс-экосистеме
- Визуальный язык — корпоративный, не выразительный

**Навигация:** поле ввода → меню «+» для файлов/картинок → история → агенты. Сложнее Perplexity.

---

### GigaChat
**Сильные стороны:**
- Работает без VPN
- Поиск в интернете появился в 2025 (веб-поиск с источниками)
- Режим «Исследовать» — глубокий анализ с выводами
- Режим «Рассуждать» — думает вслух
- Настройка тональности и глубины исследования
- Проекты и документы прямо в чате
- Маркетплейс агентов

**Слабые стороны:**
- Регистрация через Sber ID — барьер для не-клиентов Сбера
- Качество ответов нестабильно (отзывы пользователей)
- Позиционирование как «рабочий инструмент» — не для обычного поиска
- Интерфейс перегружен функциями
- Ошибки персонализации данных (по отзывам)

**Навигация:** сайдбар с историей/проектами/инструментами + центральное поле ввода. Ближе к ChatGPT.

## Что одинаково у всех

- Поле ввода в центре на главной
- История запросов в сайдбаре или отдельном разделе
- Follow-up вопросы после ответа
- Источники/ссылки к ответам
- Тёмная и светлая тема
- Минималистичный UI

**Вывод:** базовые паттерны устоялись. Пользователи их знают и ожидают.

## Где реальные возможности для дифференциации

### 1. Только поиск, без экосистемного балласта
Алиса AI и GigaChat перегружены функциями экосистем. Perplexity хорош именно фокусом.
**Возможность:** быть как Perplexity — фокус только на поиске и ответах — но с русским языком как основным и локальным контентом.

### 2. Качество локального контента
Яндекс знает локальный контекст, но UX проигрывает Perplexity.
**Возможность:** perplexity-уровень UX + качественный рунет-контент.

### 3. Прозрачность AI
Никто не делает это хорошо. «Ответ может содержать неточности» — это дисклеймер, не UX.
**Возможность:** честный UI уверенности — показывать где AI уверен, где нет, с какой даты данные.

### 4. Скорость без компромиссов
На медленном соединении все лагают.
**Возможность:** оптимизация под российскую инфраструктуру.

### 5. Онбординг для новой аудитории
Perplexity делает барьер низким, но всё равно ориентирован на продвинутых.
**Возможность:** ещё более низкий барьер для аудитории которая не пробовала AI-поиск.

## Рекомендация по навигации на первый релиз

На основе анализа — **Вариант А** (минималистичный, как у Perplexity):

```
Главная
  └── поле ввода (центр экрана)
  └── 3-4 примера запросов / темы дня

Страница ответа
  └── запрос
  └── прогресс загрузки
  └── ответ (стриминг)
  └── источники (компактно)
  └── follow-up вопросы
  └── поле следующего запроса

История
  └── список тредов по дате
  └── поиск по истории

Настройки (минимум)
  └── аккаунт
  └── тема (светлая/тёмная)
```

**Почему не Вариант Б (с Discover и Library):**
Discover и Library — это фичи retention, а не acquisition. Для первого релиза важнее сделать core-сценарий идеально. Discover можно добавить во втором релизе когда есть аудитория которую надо удерживать.
