# AI-поисковик для российского рынка: структура интерфейса
> Основа для вайбкодинга в Lovable.
> Собрано из ресёрча по 8 темам: инпут, главный экран, история, тарифы, артефакты, конкуренты.

---

## Продуктовый контекст

**Что делаем:** Perplexity-подобный AI-поисковик для российского массового рынка, backed by телеком-оператор.

**Ключевое отличие от конкурентов:** телеком-данные (геолокация, паттерны использования, carrier billing) дают персонализацию с нулевой конфигурацией — до первого запроса.

**Позиционирование:** поиск-первым (не чат), знакомая поисковая строка (не ChatGPT-композер), источники к каждому ответу (доверие), мягкий пейволл (базовый поиск всегда бесплатен).

**Аудитория:** российский пользователь 25–45, привык к Яндексу, видел AI хотя бы раз. Не технарь.

## Навигационная архитектура

### Таб-бар (mobile-first, 4 таба)

```
[ Главная ] [ Пространства ] [ История ] [ Профиль ]
```

- **Главная** — поиск + контекстный контент
- **Пространства** — проектные контейнеры с группировкой запросов и артефактов
- **История** — все прошлые запросы + доступ к Пространствам
- **Профиль** — тариф, настройки, подписка

### Веб-версия (сайдбар слева)

```
[Лого]
─────────────
+ Новый поиск
─────────────
Пространства
  ✈ Поездка в Сочи
  📊 Работа Q2
─────────────
История
  Сегодня
  Вчера
─────────────
[Профиль / тариф]
```

## Экраны — подробно

### 1. Главный экран (Home)

**Задача:** устранить синдром чистого листа, показать ценность за 5 секунд.

**Элементы (сверху вниз):**

1. **Хедер** — логотип + аватар/иконка профиля (справа)
2. **Геовиджет** — город + погода из телеком-данных. Нулевая настройка, мгновенная персонализация. `Москва · +4° пасмурно`
3. **Поисковая строка** — full-width, rounded, плейсхолдер с анимированной ротацией 3–4 примеров запросов. Иконка микрофона справа. Выглядит как поисковая строка, не как чат.
4. **Чипы режимов** — горизонтальный скролл: `Все · Новости · Покупки · Учёба · Рядом`. Первый — активный по умолчанию.
5. **Трендовые запросы** — "Популярно в [городе]", 4–5 пунктов, кликабельны. Берутся из агрегированных данных региона.
6. **Персонализированная карточка** (только для возвращающихся) — "Продолжить: [последний запрос]"
7. **Промо-баннер** (только для новых) — "3 запроса бесплатно · Без регистрации"

**Состояния:**
- Новый пользователь: видит промо-баннер, без персонализированной карточки
- Возвращающийся: видит карточку продолжения, трендовые адаптированы под историю

---

### 2. Состояние поиска (Search active)

Появляется когда пользователь тапнул на поисковую строку.

**Элементы:**
- Строка активна, курсор мигает
- Под строкой — 3 подсказки-чипа (меняются по времени суток):
  - Утро: `Пробки · Погода · Новости`
  - День: `Где пообедать · Курс валют · [персональное]`
  - Вечер: `Что посмотреть · Рецепты · Акции`
- При вводе — автодополнение построчными чипами (паттерн Яндекса для мобайла)
- Ответ-в-подсказке для фактических запросов (курс, погода)

### 3. Экран результатов (Search Results)

**Структура:**

```
[← Назад]  [поисковая строка с запросом]
──────────────────────────────────────
[прогресс-бар стриминга]
──────────────────────────────────────
Источники: [1 ЦБ РФ] [2 РБК] [3 БКС] [+2]
──────────────────────────────────────
Ответ AI с инлайн-цитатами¹²
──────────────────────────────────────
Уточнить запрос:
  › Прогноз на следующую неделю
  › Как купить выгодно
  › Курс евро
──────────────────────────────────────
[👍] [👎] [Искать в вебе ↗] [Сохранить]
```

**Ключевые паттерны:**
- Источники — блоком ДО ответа (паттерн Perplexity, формирует доверие)
- Ответ стримится (не появляется целиком)
- Цитаты инлайн — надстрочные числа `¹²³`
- 2–3 follow-up вопроса после ответа (предсказываются моделью)
- Дисклеймер внизу: "Ответ создан AI на основе открытых источников. Может содержать неточности."
- Кнопка "Сохранить" → создаёт артефакт или добавляет в Пространство

**Индикатор загрузки:**
`Ищу в источниках... · Анализирую 5 результатов... · Формирую ответ...`

- Поиск по истории — иконка лупы вверху
- Свайп влево → удалить / добавить в Пространство

### 5. Пространства (Spaces)

**Что такое Пространство:**
Именованный контейнер для группировки связанных запросов, сохранённых артефактов и загруженных файлов вокруг одной темы/проекта.

### 6. Артефакт (результат сохранения)

Появляется когда пользователь нажал "Сохранить" на результате поиска.

**Типы для MVP:**
- Текстовый документ (саммари ответа)
- Таблица сравнения (из структурированного ответа)
- Исследовательский бриф (с источниками)

**UX создания:**
1. Пользователь нажимает "Сохранить" под ответом
2. Появляется bottomsheet: `Сохранить как → [Заметка] [Документ] [В пространство]`
3. Выбирает тип → артефакт появляется в Истории с иконкой типа

**Экран артефакта:**
```
← [Курс доллара — анализ]    [↓ Скачать]
──────────────────────────────────────
[Редактировать через AI ↗]
──────────────────────────────────────
# Курс доллара: обзор

По данным ЦБ РФ на 2 апреля...
[источник ЦБ РФ]

Прогноз аналитиков...
[источник БКС]
──────────────────────────────────────
Экспорт: [PDF] [DOCX] [Копировать]
```

## Ключевые UX-паттерны (резюме)

### Что точно делаем

| Паттерн | Источник | Причина |
|---------|----------|---------|
| Поисковая строка (не чат-интерфейс) | Perplexity, Яндекс | Ниже барьер принятия для массовой аудитории |
| Источники блоком ДО ответа | Perplexity | Формирует доверие, 85% retention у Perplexity |
| Мягкий пейволл | Perplexity, Алиса | Базовый поиск всегда бесплатен |
| Геовиджет из телеком-данных | Уникально | Мгновенная персонализация без настройки |
| Анимированный плейсхолдер с ротацией | GigaChat | Решает синдром чистого листа |
| Follow-up вопросы после ответа | Perplexity | Удерживает в сессии, +depth |
| Пословные чипы при вводе (мобайл) | Яндекс | ЙЦУКЕН тяжёлый, длинные русские слова |
| Carrier billing апгрейд за 3 тапа | Телеком-специфика | +10-14 п.п. к конверсии vs. карта |
| Пространства как контейнеры | Perplexity Spaces | Организация без ручной работы |
| Инкогнито-режим | Claude | Приватность = доверие |

### Что НЕ делаем на MVP

- Не открываем артефакты автоматически (ChatGPT Canvas anti-pattern)
- Не блокируем поиск при достижении лимита (жёсткий пейволл = отток)
- Не требуем регистрацию для первых 3 запросов
- Не показываем более 5 трендовых запросов (перегрузка)
- Не делаем сложный онбординг (пользователь закроет)

## Сценарии (User Flows)

### Сценарий 1: Новый пользователь, первый запрос
```
Открыл приложение
→ Видит: геовиджет + поисковая строка + тренды + промо-баннер
→ Тапает на трендовый запрос "Курс доллара"
→ Видит прогресс-бар + источники + стримящийся ответ
→ Читает ответ, тапает follow-up
→ После 3-го запроса: мягкий bottomsheet "Сохраняйте историю — войдите по номеру"
→ СМС-верификация (1 шаг) → авторизован
```

### Сценарий 2: Возвращающийся, продолжает исследование
```
Открыл приложение
→ Видит: карточка "Продолжить: Поездка в Сочи" + персональные тренды
→ Тапает карточку → открывается Пространство
→ Делает новый запрос внутри Пространства
→ Сохраняет результат в документ → экспортирует PDF
```

### Сценарий 3: Апгрейд на Плюс
```
Исчерпал 5 Pro-запросов
→ При следующем Pro-запросе — bottomsheet (базовый поиск продолжает работать)
→ Тапает "Плюс 199 ₽/мес"
→ Подтверждение по номеру телефона (carrier billing)
→ Апгрейд завершён, продолжает запрос
```
