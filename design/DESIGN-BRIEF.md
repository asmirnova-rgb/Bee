## 2. UX-аудит конкурентов

### Что делает Perplexity хорошо

**Снижение барьера входа.**
Поисковое поле выглядит как обычный поиск — пользователь не чувствует, что учится новому инструменту. Работает даже с короткими запросами как в Google.

**Прогресс вместо ожидания.**
Пока идёт поиск, пользователь видит промежуточные шаги — это снижает тревогу ожидания и объясняет что происходит. Итеративный UI показывает план выполнения шаг за шагом.

**Доверие через источники.**
Каждый ответ содержит кликабельные цитаты. Это не просто фича — это фундамент доверия к продукту. Hover на источнике показывает сниппет прямо в интерфейсе.

**Путь вперёд всегда виден.**
Follow-up вопросы предлагаются автоматически. Discover-раздел с ежедневными темами вовлекает даже когда у пользователя нет своего запроса. Пользователь никогда не в тупике.

**Разговорный язык интерфейса.**
«Ask a follow-up...» вместо «Enter query». Небольшое решение — большой эффект на ощущение продукта.

### Что одинаково у всех конкурентов

- Поисковое поле в центре на главной
- Двухколоночный layout: ответ + источники
- Тёмная/светлая тема, минималистичный UI
- История запросов в сайдбаре
- Похожие запросы в конце ответа

**Вывод:** UX-паттерны устоялись и понятны пользователю. Перепридумывать навигацию — риск без выигрыша. Дифференциация — в деталях взаимодействия и визуальном языке, а не в структуре.

## 3. Принципы UX

*(Черновик. Уточнить после кик-оффа и первых пользовательских инсайтов)*

**Скорость важнее полноты.**
Пользователь хочет ответ быстро. Если нельзя ускорить — показывай прогресс. Никогда не оставляй в пустоте ожидания.

**Доверие строится через прозрачность.**
Каждое утверждение подкреплено источником. Пользователь должен мочь проверить — даже если не проверяет.

**Не заставляй учиться.**
Интерфейс должен работать с привычным поведением, а не требовать нового. Знакомые паттерны — не слабость, а уважение к пользователю.

**Путь всегда продолжается.**
После каждого ответа пользователь видит куда двигаться дальше. Нет тупиков, нет пустых экранов.

**Локальный контекст — это честность.**
Российские источники, локальные реалии, актуальные данные. Не делать вид что мир глобальный когда запрос локальный.

### Контракты компонентов

#### SearchInput
```json
{
  "type": "SearchInput",
  "variant": "default",
  "props": {
    "placeholder": "string",
    "value": "string",
    "isLoading": "boolean",
    "suggestions": "string[]"
  }
}
```
**Description:** Главное поле ввода. Работает как привычный поиск — короткие запросы, длинные вопросы, всё принимает.  
**Rules:** Placeholder должен быть вопросом, не инструкцией. Пустой запрос не блокируется — показывать подсказку и пример запроса, но не ошибку формы.
